# MAKEFILE

## COMANDOS

|comando|utilidade|
|-------|---------|
|`all`| ele compila o projeto, e suas dependencias|
|`run`| ele executa o projeto, e caso não tenha compilado, já compila|
|`clean`| ele limpa o aquivo compilado|
|`rebuild`| ele limpa e compila novamente o projeto (clean all)|
|`restart`| ele limpa, compila e executa o projeto (clean all run)|
|`tokenize`| ele executa o projeto de forma que mostre os tokens gerados|
|`parserize`| ele executa o projeto de forma que faça a parserização do projeto|

## ENFASÊ

o modo run ele executa a ultima implementação (atualmente no parser).
